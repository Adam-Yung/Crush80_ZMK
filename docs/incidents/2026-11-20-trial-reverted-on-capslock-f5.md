# 2026-11-20: a trial dropped off USB when F5 was pressed with Caps Lock held

**What happened:** the private image (single-colour backlight per layer, Base off) ran as a trial; everything worked until the owner pressed F5 while holding Caps Lock (Nav layer, where F5 is bound to nothing). The keyboard dropped off USB, and after a replug it was running the previous confirmed image. The backlight stayed off on it.
**Likely explanation (unproven):** a wedged system work queue starved the 2 s watchdog heartbeat, the 11 s watchdog reset the chip, and MCUboot reverted the unconfirmed image. If so this is the first evidence that a watchdog reset also reverts a trial (hardware test plan T5), and the safety net did its job. It also means a real firmware fault exists; its cause is not known. Reading the code finds nothing on that key path (F5 in Nav is `&none`).
**Why no backlight afterwards:** explained and harmless: the owner had toggled the backlight during the trial and ZMK saved "off" to flash; the older image restored that.
**Open:** reproduce on a trial (hold Caps alone for 15 s; F5 on Base; tap Caps ten times). A power glitch from the LED supply switching on when leaving Base is the first suspect. The per-key engine replaces the code that was running then, so the check is repeated with it. No crash breadcrumb exists yet (a reset leaves no trace once the previous image is back).
