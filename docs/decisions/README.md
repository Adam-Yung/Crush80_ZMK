# Decision log

One file per topic, named `<kebab-case-topic>.md`. Entries are **append-only**: dated, newest at the bottom, never edited or deleted. A reversal is a new entry that says so.
This records decisions made while building: a mechanism chosen, a tradeoff taken, an option rejected and why. A sentence or two each; substantial design belongs in `docs/features/`.

Topics: `install-safety`, `keymap-private`, `rgb`, `tooling`.
